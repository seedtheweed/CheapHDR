# CheapHDR
#### Backstory
I always liked how Ambilight and Govee setups looked like, but I could never bring myself to justify the price. Unlike TV screen sync LED setups, a monitor setup is far cheaper, so I got cheap led backlights for my monitor from the Tiktok shop. Because of how cheap they are, they used a single usb connection to my computer using an app called DX light.   I often left them unplugged, since they would turn on in the middle of the night when my computr update
